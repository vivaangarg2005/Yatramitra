# 🌟 YatraMitra – India’s Smart Tourism Companion (Smart India Hackathon 2025)

YatraMitra is a government-backed, cloud-native platform designed for the **Smart India Hackathon 2025** under the Travel & Tourism theme. It helps tourists, governments, and local communities make smarter, eco-conscious, and personalized travel decisions — all in a single trusted app.

---

## 🚀 Problem Statement

Tourists and citizens face challenges like:

* Fragmented travel information
* Lack of personalized guidance
* Weak promotion of sustainable tourism
* Limited data-driven insights

Governments struggle with:

* Efficient resource utilization
* Economic leakage from tourism
* Lack of policy-making insights

---

## 💡 Our Solution

**YatraMitra** bridges these gaps by offering:

### For Travelers

* Personalized itineraries
* Budget-friendly and safe planning
* Eco-conscious travel recommendations

### For Governments

* Comprehensive tourism data analytics
* Smarter policymaking
* Support for regional development and sustainability

### For Local Communities

* Promotion of remote and underutilized destinations
* Support for SMEs and local businesses

---

## 🏆 Key Features

* **Dynamic Trip Planner** – Plan trips by budget, destination, and duration
* **Interactive Dashboard** – Provides governments with actionable insights
* **Sustainability Focus** – Encourages eco-conscious travel choices
* **Local Business Promotion** – Highlight hidden gems and SMEs
* **Mobile-First Experience** – Fully responsive and user-friendly

## 🎨 UI & Components

The project uses the following **React components**:

* `Navbar.jsx` – Navigation bar with responsive menu
* `Hero.jsx` – Hero section with trip planner form and main illustration
* `Destination.jsx` – Destination selection and details
* `Features.jsx` – Showcase of app features
* `HowItWorks.jsx` – Step-by-step guide for using the app
* `HiddenGems.jsx` – Highlighting remote and underutilized destinations
* `Impact.jsx` – Shows the social, economic, and environmental impact
* `Footer.jsx` – Footer with links, contact, and social media

The project also contains:

* `index.css` and `app.css` in `src/` for global and app-specific styling.

All components use **Tailwind CSS** for styling and **Framer Motion** for smooth animations.

## ⚡ Usage

1. Clone the repository:

```bash
git clone https://github.com/your-username/yatra-mitra.git
```

2. Install dependencies:

```bash
cd yatra-mitra
npm install
```

3. Start the development server:

```bash
npm run dev
```

4. Open your browser at [http://localhost:5173](http://localhost:5173)
